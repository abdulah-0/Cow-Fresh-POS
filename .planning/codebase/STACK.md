# Technology Stack

## Core
- **Framework**: Next.js 16.0.10 (App Router)
- **Language**: TypeScript
- **Frontend Library**: React 19.2.3

## Styling
- **CSS**: Tailwind CSS 4
- **UI Components**: Radix UI
- **Icons**: Lucide React
- **Animations**: tw-animate-css

## State Management & Logic
- **Global State**: Zustand 5.0.8
- **Forms**: React Hook Form 7.66.1
- **Validation**: Zod 4.1.12
- **Data Fetching**: Supabase SSR (@supabase/ssr)

## Backend & Database
- **Provider**: Supabase
- **Database**: PostgreSQL
- **Authentication**: Supabase Auth

## Utilities
- **Date Handling**: date-fns
- **PDF Generation**: @react-pdf/renderer
- **Barcode**: jsbarcode, react-barcode
- **Table Management**: TanStack Table (react-table)
- **Charts**: Recharts
- **Excel Export**: xlsx
