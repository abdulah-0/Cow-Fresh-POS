# Requirements

## Functional Requirements

### 1. POS Billing System
- [ ] Fast billing interface with barcode support.
- [ ] Weight-based item calculation (KG, Liter).
- [ ] Automatic subtotal, discount, and tax calculation.
- [ ] Support for Cash and Mobile Wallet payments.
- [ ] Printable receipts (PDF).

### 2. Product & Inventory
- [ ] Product attributes: SKU, Category, Unit Type (KG/Liter/Piece), Purchase/Selling Price.
- [ ] Expiry date tracking and batch management.
- [ ] Real-time stock tracking with low-stock and expiry alerts.
- [ ] Wastage/Damaged stock recording.

### 3. Customer & Loyalty
- [ ] Customer database with purchase history.
- [ ] Tier-based loyalty system (points-based discounts).

### 4. Admin & Reporting
- [ ] Role-based access control (Admin, Manager, Cashier).
- [ ] Daily, weekly, monthly sales reports.
- [ ] Profit/Loss and Expense tracking.

## Non-Functional Requirements
- [ ] Response time under 2 seconds.
- [ ] Secure role-based access.
- [ ] Mobile/Tablet responsive design.
- [ ] Premium "Dairy Fresh" aesthetic.
